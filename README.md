# Mauzi-code
Open source AI Agent like Claude Code, but better :)

# How to download
Actual applications is sorted in releases.
-----------------------------------
1 - Open releases |
2 - Pick the latest version and download |
3 - Unzip the .rar folder |
4 - follow the instructions below |

# Build

Win + R, cmd:
```text
cd Mauzi-code-dev
npm install
npm run dev
```

# Languages
